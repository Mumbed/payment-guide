# 명성왕만두 - 송금 안내

부모님 가게 송금을 위한 모바일 최적화 웹페이지입니다.

## 🎯 기능

- **계좌번호 표시**: 국민은행 034501-04-073572
- **토스 송금**: 토스 앱으로 자동 이동 (앱 없으면 웹)
- **계좌번호 복사**: 클립보드에 한 번에 복사
- **모바일 최적화**: 모든 기기에서 완벽하게 표시
- **깔끔한 디자인**: 직관적이고 간단한 UI

## 🔧 설정

`script.js`의 `CONFIG` 객체를 수정하세요:

```javascript
const CONFIG = {
    bank: '국민은행',              // 은행명
    account: '034501-04-073572',    // 표시용 계좌번호
    accountNumber: '03450104073572', // 실제 계좌번호 (숫자만)
    accountHolder: '원재인',        // 예금주명
    bankCode: '004'                 // 은행 코드
};
```
